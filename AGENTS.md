# Instrucciones del proyecto

Proyecto: ENTRENADOR DE FUTBOL FEMENINO SUB 17 PALOMETAS.

- Implementar los cambios solicitados y subirlos al repositorio dentro del alcance autorizado por el usuario.
- No ejecutar pruebas automatizadas, comprobaciones manuales de funcionamiento ni sesiones de navegador para probar los cambios, salvo que el usuario lo pida expresamente. El usuario se ocupa de las pruebas.
- Se puede consultar el estado de guardado y de publicación en GitHub para confirmar la entrega, esto no implica probar las funciones de la página.
- En Entrenamientos, dirigir las indicaciones a Juan con voseo, él lee y guía la práctica. Usar comas en lugar de puntos y coma en los textos visibles.
- No mostrar comentarios ni enlaces de FIFA 11+ u otras fuentes de preparación en el recorrido. Mantener las consignas prácticas.
- Usar posición habitual y segunda posición del plantel para sugerir grupos y puestos, sin modificar las fichas al organizar una práctica.
